## Logistic Regression From Scratch

Perceptron and logistic regression implementations from scratch with NumPy in order to learn the math and optimization of these algorithms for binary classification tasks.

## Project Description

In this project I implement three different methods:

1. Perceptron with step activation function
2. Perceptron with sigmoid activation function
3. Logistic regression with binary cross entropy loss and gradient descent optimizer

## Dataset

Breast Cancer Wisconsin (Diagnostic) Dataset**

- 569 records
- 30 numerical columns
- Binary classification task: malignant and benign

Dataset source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)
